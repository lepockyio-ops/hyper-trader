# 规格审查子 agent 任务模板（由 s03-research 用 sessions_spawn 派生，context 选 isolated）

你只拿到两样东西：docs/STRATEGY_TEMPLATE.md 里填好的策略规格、手册第 7 节（仓位、风险）的规则表原文，以及本次改动的代码文件。
不要参考其他上下文，不要运行代码，不要修改任何文件。

逐条检查每一条规则是否在代码里实现，且口径一致。重点核对：
- 所有阈值的数值和比较方向（< 还是 ≤、百分比还是小数）；
- “改用 X 之后仍不满足”这类二次检查是否存在（v0.x 的最小止损问题就出在这里）；
- 成本、资金费、杠杆、强平距离的公式与手册是否一致；
- 回测与实盘是否走同一段代码。

输出一个表格：规则 | 代码位置（文件:行） | 一致 / 不一致 / 未实现 | 说明。没有把握的写“未知”，不要猜。
